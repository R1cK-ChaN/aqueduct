# Measurement notes

Each note records the question, the method, the site, the sample date and
extent, and the exact inputs. For a feed measurement, include the subscription
messages and symbol lists. Give the results and their limitations, and link
the venue register entries that cite the note.

Start the filename with the sample date. Never rewrite a dated note. Private details
may be removed if the note records the kind of detail removed and the date.
A later measurement gets a new note.
